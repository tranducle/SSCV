# Code and Data Availability

The SSCV reproducibility code is available in this repository. It contains the verification implementation, controlled-study code, public-source replay logic, frozen sampling and mapping manifests, pinned dependencies, deterministic regression tests, and replication instructions.

The two simulated OCEL 2.0 sources used in the evaluation are available from Zenodo:

- Procure-to-Payment: DOI `10.5281/zenodo.8412920`.
- Order Management: DOI `10.5281/zenodo.8428112`.

Raw dataset files are not redistributed. The included download utilities verify the version-pinned public sources before use. No proprietary enterprise data or real insider-incident records are distributed or required.

No software license is asserted unless a license file is explicitly added by the repository owner.
